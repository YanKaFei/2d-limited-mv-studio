# 2D Limited MV Studio

**Une image de personnage + une chanson → un package de prompts complet pour un clip anime 2D.**

Un Agent Skill DeepSeek Harness qui transforme une image de personnage et une chanson en package de prompts vérifié pour **MiniMax H3** : montage musical de 14,5 s, mouvements artistiques traversés, objets-lyrics dans le décor, caméra 2D qui ne quitte jamais le papier, segments enchaînés par la dernière image.

[中文](README.md) · [English](README.en.md) · [한국어](README.ko.md) · [日本語](README.ja.md) · **Français**

## Ce que vous obtenez

- montage musical à 14,5 s
- langage caméra 2D limited
- distribution de mouvements artistiques
- objets-lyrics intégrés au décor
- continuité entre segments
- pas de 3D, le skill ne génère pas la vidéo

## Installation

```bash
./install-to-dsh.sh
```

Ou utilisez `SKILL.md` dans un environnement compatible.

## Usage

Donnez une image de personnage et une chanson : le skill renvoie un package de prompts et un plan de shots pour MiniMax H3. **Texte uniquement** ; il ne génère pas la vidéo finale.
