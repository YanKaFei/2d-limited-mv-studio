# 魔性动作设计 · 让舞蹈「停不下来」

> **魔性不是「动作多」，是「同一个动作反复出现」。**
> 一支舞之所以洗脑，不是因为编舞复杂，恰恰是因为它**简单到你能跟着做，然后做了八遍**。

---

## 一、三层设计

| 层 | 字段 | 决定什么 |
|---|---|---|
| **魔性度** | `seg.motion.viral_level` | 这一段重复得有多狠（0 克制 → 3 洗脑） |
| **循环表** | `seg.motion.*` | 动作单元几拍、几小节一循环、重复几次、第几次变异、用哪种变体 |
| **hook** | `plan.motion_design.hook_id` | 全片**唯一**的记忆点动作，副歌必出现 |

```bash
python3 scripts/mvstudio.py motion                          # 看菜单 + 当前设计
python3 scripts/mvstudio.py motion --hook shoulder_pop_8
python3 scripts/mvstudio.py motion --viral 3                # 全片洗脑档
python3 scripts/mvstudio.py motion --segment C2 --viral 0   # 单段克制
```

魔性度**逐段自动推**（低谷→克制，峰值→魔性），可以手改；手改过的段重跑不会被覆盖。

---

## 二、魔性度四档

| 档 | id | 动作单元 | 循环 | 重复次数 | 变异 | 适合 |
|---|---|---|---|---|---|---|
| 0 | `restrained` 克制 | 2 拍 | 2 小节 | 1–2 | 每轮 | 主歌开头、安静段 |
| 1 | `groove` 律动 | 2 拍 | 2 小节 | 2–3 | 每 2 轮 | 推进段 |
| 2 | `hooky` 魔性 | 1 拍 | 1 小节 | 4–6 | 每 4 轮 | **默认**；副歌 |
| 3 | `brainworm` 洗脑 | 1 拍 | 1 小节 | 6–10 | 每 8 轮 | 最洗脑的副歌 |

> **动作单元只有 1–2 拍**，这是关键。4 拍的长句做不了重复——你没时间做第二遍。

---

## 三、循环表：为什么必须从拍网格推

「每段重复 4 次」是拍脑袋。真正的循环周期由**节拍**决定：1 小节一循环还是 2 小节一循环，
直接决定观众能不能跟上、能不能记住。

这一条不是我们的发明——**公开的音乐驱动舞蹈生成研究全部建立在这个前提上**：

| 研究 | 给什么 |
|---|---|
| [AMAP-ML/MACE-Dance](https://github.com/AMAP-ML/MACE-Dance)（SIGGRAPH 2026） | 音乐条件驱动的舞蹈生成 |
| [verlab/Learning2Dance](https://github.com/verlab/Learning2Dance_CAG_2020) | 图卷积的舞蹈生成 |
| [libuyu/PhantomDanceDataset](https://github.com/libuyu/PhantomDanceDataset)（DanceFormer） | 音乐→舞蹈数据集与对齐方式 |
| [DeepVTuber/DanceNet3D](https://github.com/DeepVTuber/DanceNet3D) | 基于音乐的 3D 舞蹈 |
| [xjli360/SoulDance](https://github.com/xjli360/SoulDance-Official) | 层次化音乐对齐的整体舞蹈生成 |

> **我们只采纳「动作周期由节拍/起音驱动」这一条原理，不引入它们的任何依赖**——
> 本技能仍然是零第三方依赖。这些是**生成**动作的模型，我们做的是**设计规格**，不是同一件事。

循环表长这样（每段一张，可直接校验）：

```jsonc
{
  "viral_level": 2, "viral_name": "hooky",
  "unit_beats": 1,        // 动作单元占几拍
  "cycle_bars": 1,        // 几小节一个循环
  "repeats": 6,           // 连续重复几次
  "mutation_at": [4],     // 第 4 次做变异
  "variations": ["half_time"],   // 变异方式
  "total_beats": 24,      // 总占拍数 —— 不能超过这一段实际拍数
  "hook_id": "shoulder_pop_8",
  "degraded": false       // 没有可靠拍网格时会标 true，退化为按秒
}
```

**硬约束**：`total_beats` 不能超过这一段实际拍数。写不动作的要求等于废纸，
所以校验器会拦。

## 四、五种重复变体（魔性靠它们，不靠换动作）

| id | 做法 | 为什么有效 |
|---|---|---|
| `accent_grow` 递增强调 | 每次重复幅度更大 | 观众跟着一起使劲 |
| `double_time` 双倍速 | 后半段同动作两倍速 | 动作不变、体感翻倍 |
| `half_time` 半速拖拍 | 像卡带被拉慢 | 制造「不对劲」 |
| `offset_half_beat` 错位半拍 | 晚半拍进入，与音乐形成卡农 | 听得见的两层 |
| `drop_last_rep` 末次截断 | 最后一次只做一半停住 | **上瘾之后戒断一下** |

> 铁律：**变异是同一个动作的变奏，不是换一个动作。** 换了动作，记忆点就断了。

## 五、八种记忆点动作（hook）

**全片只有一个。** 多张等于没有记忆点。

| id | 名称 | 做什么 | 为什么魔性 |
|---|---|---|---|
| `head_bob_lock` | 点头锁 | 身体完全不动，只有头在重拍上点一下 | 只有一部分在动，最省也最魔性，且完全保 2D 平面感 |
| `shoulder_pop_8` | 抖肩八连 | 同一侧肩抖八下，第八下整个人弹出去 | **计数本身就是笑点** |
| `stomp_pause` | 跺脚停顿 | 跺→停半拍→再跺，停顿越来越长 | 停顿制造期待，直到观众跟着数拍 |
| `hand_frame_swap` | 比框换手 | 双手比框，每个重拍换手，框始终不散 | 框本身就是构图装置，平面感更强 |
| `squat_pulse` | 蹲弹 | 蹲着上下弹，最高点肩线故意歪 | 挤压拉伸最容易做出「**憨**」，而憨是魔性核心 |
| `point_walk` | 指指走 | 手指东、脚往西，方向相反 | 反向协调看着别扭但停不下来 |
| `half_spin_repeat` | 半转重复 | 每次只转半圈就停，第四次转满 | **始终差一半**建立期待，第四下超额兑现 |
| `mirror_hands` | 镜像手 | 左右手相反、错开半拍 | 错半拍=天然卡农，做出「另一个自己」而不动 Canon |

> ⚠️ 所有 hook **都不改变人物身份**。动作再魔性也不换人。

## 六、十二动画原则：让重复有动感，而不是机械重复

融合 Disney 十二动画原则（动画工业通行知识；[dylantarre/animation-principles](https://github.com/dylantarre/animation-principles)
把它做成了 Claude Skill）。**只用于「怎么说」，不引入任何依赖。**

| 原则 | 在魔性动作里的用法 |
|---|---|
| 挤压与拉伸 | 蹲弹类：落地压扁、起跳拉长——2D 里就是改赛璐璐形状 |
| 预备动作 | 抖肩/转身前反向蓄一下；魔性动作的「起手」全靠它 |
| 表演布局 | hook 手势始终落在画面最清楚的位置 |
| 姿势对姿势 | 2D 有限动画主力：先定关键姿势，重复的就是它 |
| 跟随与重叠 | 头发、衣摆晚半拍；重复动作靠它才不僵 |
| 慢入慢出 | 「停住半拍」的质感来源，也是踩点感来源 |
| 弧形运动 | 手的轨迹走弧线；直线看起来像机器 |
| 次要动作 | 头部小幅跟随、指尖抖动，给重复加信息量 |
| **节奏** | **动作必须锁在重拍上——全片唯一不可让步的一条** |
| 夸张 | 魔性 = 夸张。「稍微大一点」等于没做 |
| 扎实的造型 | 重复最容易画崩比例，所以重复动作更需要守 Canon |
| 吸引力 | 「憨」也是一种吸引力——可爱是让人愿意再看一遍 |

---

## 七、五条硬规矩

1. **全片只有一张 hook。** 两张等于零张。
2. **副歌（峰值段）必须出现 hook**，至少一次完整循环。
3. **重复的起点必须落在重拍上。** 落不到重拍就不要重复。
4. **变异是同一个动作的变奏**，不是换动作。
5. **循环表总拍数不能超过本段实际拍数。**

前四条由校验器与渲染器保证；第五条会拦（否则提示词会要求做不完的动作）。
