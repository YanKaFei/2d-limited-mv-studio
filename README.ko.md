# 2D Limited MV Studio

**캐릭터 이미지 하나 + 노래 하나 → 완성된 2D 애니메이션 MV 프롬프트 패키지.**

DeepSeek Harness Agent Skill입니다. 캐릭터 이미지와 노래를 **MiniMax H3**용 머신 체크 프롬프트 패키지로 바꿉니다. 14.5초 뮤직 컷, 캐릭터가 지나가는 예술 사조, 배경에 놓인 가사 오브젝트, 종이를 떠나지 않는 2D 카메라, 이전 마지막 프레임으로 이어지는 세그먼트를 만듭니다.

[中文](README.md) · [English](README.en.md) · **한국어** · [日本語](README.ja.md) · [Français](README.fr.md)

## 제공

- 14.5초 뮤직 컷
- 2D 리미티드 애니메이션 카메라
- 예술 사조 캐스트
- 장면 속 가사 오브젝트
- 세그먼트 연속성
- 3D 없음, 스킬 자체가 영상을 생성하지 않음

## 설치

```bash
./install-to-dsh.sh
```

또는 `SKILL.md`를 읽고 호환 환경에서 사용합니다.

## 사용

캐릭터 이미지와 노래를 주면 MiniMax H3용 프롬프트 패키지와 샷 플랜을 반환합니다. **텍스트 전용**이며 최종 영상을 생성하지 않습니다.
